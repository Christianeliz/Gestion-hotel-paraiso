# Hotel Paraíso - Sistema de Gestión

Sistema completo de gestión hotelera desarrollado en Java con interfaz gráfica Swing y base de datos SQLite. 

## 🚀 Funcionalidades Principales

- **👥 Gestión de Clientes**: CRUD completo con búsqueda por nombre y DNI
- **🏨 Administración de Habitaciones**: Tipos, estados, precios y filtros  
- **📅 Control de Reservaciones**: Validación de fechas, disponibilidad y cálculo automático de costos
- **💾 Base de Datos SQLite**: Con integridad referencial y datos de muestra
- **🖥️ Interfaz Gráfica Intuitiva**: Desarrollada en Swing con formularios y tablas

## ⚡ Características Técnicas

- **Validación de Disponibilidad**: Previene reservas superpuestas
- **Cálculo Automático de Costos**: Basado en días de estadía y precio por noche
- **Búsqueda y Filtros**: En todas las entidades del sistema
- **Manejo de Estados**: Para habitaciones y reservaciones
- **Validaciones Robustas**: Fechas, emails, DNI únicos

## 🛠️ Tecnologías

- Java 17, Swing, SQLite, Maven, JDBC
